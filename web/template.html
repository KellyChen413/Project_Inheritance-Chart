使用說明與資安說明
  • 本檔案為單一 HTML 檔，用 Edge 或 Chrome 直接開啟即可使用，不需安裝任何軟體，也不需要網路。
  • 檔案內設有安全政策，瀏覽器會封鎖任何對外連線；程式碼為純文字，可由資訊單位直接檢視。安全政策以「雜湊值」只允許本檔案內既有的程式與樣式執行，檔案若遭竄改或被插入其他程式碼，瀏覽器會拒絕執行。
  • 輸入的資料只存在本頁面的記憶體中，不會寫入硬碟或瀏覽器儲存空間，關閉分頁即清除。若需保存，請按「匯出案件檔」並依單位規定保管。全程不使用 localStorage、sessionStorage、IndexedDB 或 Cookie；欄位對應設定也只在本次開啟期間記住。
  • 戶籍資料匯入（實務流程）：按「匯入檔案」選擇從戶役政系統匯出的 Excel（.xlsx／.xls）、PDF 或 CSV，可一次選多份、混合不同格式。系統會自動判斷是「親等關聯資料」「戶籍謄本」還是「個人戶籍資料」，並自動辨識欄位、直接匯入（戶役政二親等匯出的 16 個欄位都已內建；「項目」「查看」等畫面操作欄自動略過）。只有缺少必要欄位、無法辨識時才會跳出對應視窗；想逐檔確認，可勾選「匯入前確認欄位」。同一人出現在多份資料時，以統一編號合併；被查詢人的稱謂為「自己」（也接受「本人」），日期可為 0370512 這類民國 7 碼；親屬關係依「稱謂（相對於被查詢人）」、父母配偶統號與「父、母、配偶姓名」自動串聯；稱謂會依被繼承人重新換算。
  • PDF 匯入：可直接匯入戶政系統匯出的文字型 PDF（能用滑鼠選取文字者）。系統依文字位置還原表格，支援跨頁與儲存格換行；也能讀取「姓名：○○」這類表單格式。匯入前請在對應視窗核對預覽內容。掃描影像 PDF 沒有文字層，無法讀取。PDF 讀取元件（pdf.js）與中文字碼表已內嵌於本檔，不需連網。
  • 待調閱清單：系統會判斷還需要調閱誰的資料，例如繼承開始前死亡且查無子女者、繼承開始後死亡（再轉繼承）者。調閱後查無資料，可按「已調閱／已確認」。
  • 拋棄繼承查證：系統表下方列出需查證的人，至法院家事事件公告查詢後登錄結果、法院與案號。查證結果分為「查無拋棄」「已聲明拋棄（待核實）」「已拋棄（已核實）」；已聲明者先納入計算，但標示待核實文件。尚未查證完成前，系統表會標示「尚非最終結果」。
  • 日期可輸入民國（例：114/3/10）或西元（例：2025-03-10）。
  • 謄本輸入（紙本戶籍謄本）：按「謄本輸入」，一份謄本輸入一次。稱謂填「與戶長的關係」，戶長本人填「戶長」。記事欄照抄或貼上即可，系統會自動抓出死亡（含死亡宣告的推定死亡日）、更名（原名列入父母姓名比對）、結婚、離婚，下方即時顯示解析結果；收養、多次婚姻或看不懂的記事會提醒人工確認。謄本的資料與戶役政匯入的資料以統一編號合併、互相補足。謄本不等於二親等資料，戶長不會被當成「已調閱」。
  • 適用法律時點：本系統只實作現行民法。被繼承人於民國34年10月25日前（日據時期）死亡者，繼承依當時臺灣習慣判斷，系統不產生應繼分；民國74年6月5日民法繼承編修正施行前開始的繼承，會提醒部分規定不同（例如養子女應繼分），請人工確認。這類舊案多半只有手抄或日據時期謄本，仍可用「謄本輸入」建檔。
  • Excel 匯入：直接選擇戶役政匯出的 .xlsx 或 .xls，不必先另存為 CSV。系統讀取第一張工作表，表頭上方的標題列會自動略過。Excel 把 0370512 顯示成 370512（前面的 0 被去掉）也能正確辨識；儲存格若是 Excel 日期格式，會自動換算。讀取全程在瀏覽器內完成，不使用任何外掛或網路。有密碼保護的檔案請先移除密碼。
  • 變更註記：「統號變更註記」「姓名變更註記」為空白表示沒有變更；為「*」表示曾經變更，但匯出檔沒有寫出舊統號或舊名，系統會在匯入訊息與待辦清單提醒人工確認（例如子女資料上的母親姓名是舊名）。父母配偶有填統號時，仍以統號連結，不受改名影響。
  • CSV 匯入：按「下載 CSV 範本」用 Excel 填寫，存檔後按「匯入資料」。父、母、配偶直接填姓名；有同名者改填「編號」欄的編號。拋棄、喪失欄填「是」代表對被繼承人；再轉部分的拋棄填該再轉被繼承人的姓名。稱謂填「被繼承人」的那一列即為被繼承人。Excel 一般 CSV（Big5）與 CSV UTF-8 都能讀取。
  • Excel 日期注意：在 Excel 輸入「37/5/12」這類兩位數民國年，會被自動改成西元 1937 年。民國 100 年以前的日期請寫成「民國37年5月12日」或西元「1948/5/12」，或先將日期欄設為文字格式。
  • 「喪失」欄是指對目前選定之被繼承人喪失繼承權（第1145條）。拋棄繼承請在「拋棄繼承查證」登錄，含再轉部分的拋棄。
  • 資安設計：不使用 localStorage、sessionStorage、IndexedDB 或 Cookie；輸入框關閉瀏覽器自動填入紀錄；離開或重新整理頁面時主動清空記憶體中的資料；畫面一律以 textContent 輸出文字，不使用 innerHTML，防範 XSS；下載檔名只含日期、不含姓名，避免下載資料夾的檔案列表洩漏個資。
  • 胎兒：繼承開始時已受胎、尚未出生者，在出生日期下方將胎兒狀態設為「待出生」，系統依民法第7條、第1166條保留其應繼分，並標示本表尚非最終結果；出生後改為「已活產」並填出生日期；死產者設為「死產」，系統會重新計算。
  • 同日死亡：繼承人與被繼承人同日死亡時，可在死亡日期下方填寫時間（24 小時制）判斷先後；未填時依民法第11條推定同時死亡，並列為待確認事項。同時死亡者的子女仍得代位繼承（通說）。
  • 婚姻終止：配偶欄下方可填婚姻終止（如離婚）日期；於繼承開始前終止者，不具配偶繼承權。
  • 分次繼承系統表：繼承人於遺產分割前死亡（再轉繼承）時，系統會為每一次死亡各產生一張繼承系統表，例如父親死亡為第 1 次、其後次子死亡為第 2 次；稱謂改以該次的被繼承人為準，方塊中以藍字標示占原遺產的比例。畫面上用上方按鈕切換，列印時每一次各印一頁。可按「三代綜合案例」查看示範。
  • 次親等遞補：第一順序親等近者中得繼承者均拋棄時，依民法第1176條第5項由次親等直系血親卑親屬按人數繼承；先死亡且無人代位者本非繼承人，不列入「均拋棄」的判斷，判斷過程中會逐一列出。
  • 查無繼承人：系統只會顯示「目前查無繼承人」，不會直接判定無人承受；確認無人承受（民法第1177條）前，應先完成親屬調查。
  • 系統表與明細會自動加註備註：拋棄繼承、喪失繼承權、代位繼承、再轉繼承等情形，均註明條文依據。
  • 適用現行民法第1138～1144、1176條；尚未處理舊法適用、收養、遺囑及特留分，結果僅供承辦參考，應與戶籍資料核對。
